# 功能清单

## ✅ 已实现

### 账号与安全

- 用户名 + 密码登录，真实请求 Cloudflare Worker（`POST /api/auth/login`），密码 PBKDF2-SHA256 加盐散列
- 登录态为随机 token，服务端只存 SHA-256，可主动注销，默认 30 天过期
- **应用内没有注册入口**，也没有注册接口；账号只能由管理员创建
- 管理员两种建号方式：App 内「设置 → 用户管理」、命令行 `npm run user:create`
- 支持管理员/普通用户两种角色，管理接口有角色校验
- 服务器地址可在登录页/设置页随时修改，换服务器不用重装

### 会话

- 会话列表：头像、名称、最后一条消息、时间、未读数
- 未读数由服务端按已读游标计算，进入会话自动清除
- 通过用户目录发起一对一聊天；已存在的单聊会复用，不会重复创建
- 群聊的数据模型、成员渲染、作者名显示已就绪（**创建群聊的 UI 未做**）

### 消息

- 发送消息真正写入 D1，服务端返回自增序号
- 乐观发送：先上屏（时钟图标），成功后换成单勾/双勾，失败显示红色感叹号，点击重发
- `clientId` 幂等：网络重试不会产生重复消息（服务端有唯一性检查）
- 分页拉取历史消息（滚动到顶部自动加载更多）
- 日期分隔（今天 / 昨天 / 日期）
- 气泡连续分组、尾部小三角、深浅色主题下的 Telegram 配色
- 已读双勾：根据对方（群聊为最大）已读游标实时更新

### 推送（安卓）

- 常驻前台服务 + 用户级 WebSocket，App 在后台/被划掉后仍能即时收到新消息
- 系统通知（标题=发送者，内容=消息），点击直接打开对应会话
- 开机自动恢复连接；退出登录自动停止并清理凭证
- 需要通知权限；国产 ROM 需放行自启动/后台运行

### 实时

- WebSocket 连接 Cloudflare Durable Object（每个会话一个实例）
- 新消息、正在输入、已读回执实时推送
- 断线自动重连（2.5 秒），并有 4 秒轮询兜底，弱网也不会丢消息
- 「正在输入…」3.5 秒自动消失

### 伪装与隐私（iOS + Android）

- 图标、名称均为「计算器」，启动页就是可用的计算器
- 输入密码（默认 `1234`）+ `=` 解锁进入聊天
- 退到后台自动锁定；设置内可改密码、关闭伪装、立即锁定
- 安卓的通知渠道 / 前台服务文案同样使用中性名字

### 界面

- 完全用 Jetpack Compose 实现，Material 3
- Telegram 风格：蓝色主色、圆角气泡、渐变头像、聊天背景纹理、浮动新建按钮
- 浅色 / 深色 / 跟随系统三种主题，状态栏图标自动反色
- 登录页、会话列表、聊天页、新建会话、设置、用户管理、启动页
- 中文文案，空状态、加载态、错误提示齐全

## 已知限制

- 群聊功能后端已支持，但客户端没有「创建群聊」入口，只能通过 API 创建
- 消息存在 D1 中，单会话历史分页每次最多 100 条；超大群/超长历史的性能未压测
- 免费版 Worker 有 10ms CPU 限制，密码散列轮数默认 25000；付费版可调高
- 聊天背景纹理是代码绘制的近似效果，不是官方壁纸资源
